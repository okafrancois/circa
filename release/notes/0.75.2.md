## Fixed

- Command-E now works with the sidebar hidden or in full screen: the sidebar slides in and Site Controls opens with the first extension outlined, even when only one extension is pinned.
- Pressing E again while holding Command moves through every extension in Site Controls, pinned or not, and wraps around. Releasing Command opens the selected extension; Escape cancels.
