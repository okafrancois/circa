## New

- Sidebar backgrounds now use native macOS translucency. The Frost switch is removed, and saved Frost values no longer change interface controls.
- Peek controls keep circular backgrounds, and Settings category labels retain their bottom padding.
- Drag one sidebar tab onto another to create a Split View. Peek gains Split button feedback, with a four-pane limit and minimum pane widths.
- Web fullscreen displays an Escape notice. Native-window fullscreen remains independent.
- AI provider foundation and Settings are available, off by default. Assistant and helper features remain hidden while they are being built.
- another browserhive preview close and Library hide behavior has additional regression and stress coverage.
