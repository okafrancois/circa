## New

- Describe a page appearance change in a Boost’s Code editor to generate CSS with your selected Chat model.
- Review the streamed draft and its live preview, edit it if needed, then choose **Apply** to save it for the site. Saved changes survive reload and relaunch.
- Stop, close, prompt changes, navigation and policy changes cancel the draft and restore the saved appearance. Existing manual CSS and JavaScript editing remain available.

## Known limits

- Generated changes support a validated CSS subset and bounded visible main-frame page structure. Generated JavaScript is not included in this version.
- AI must be enabled with a ready Chat model. Site exclusions, private-window restrictions, quotas and page-reading preferences apply.
