Native overlay scrollbars for web pages.

- Added “Overlay scrollbars on web pages” in Advanced Settings, off by default.
- When enabled, thin native scrollbars float over page content and fade away when idle, including on sites that style their own scrollbars.
- Restart Circa after changing the option. Turning it off restores the usual system and website presentation.
- Scrollbars explicitly hidden by a site stay hidden.
