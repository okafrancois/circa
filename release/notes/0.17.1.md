## Fixed

- Opening Boosts, changing Spaces and closing previews no longer leave a stale editor attached to another page. Finishing Zap returns focus to the document.
- Back, Forward and form navigation preserve the page's navigation details.
- Space symbol icons draw upright, and the switcher's hover label shows the Space name and shortcut.

## Smaller

- The Command Bar uses a blurred translucent background.
