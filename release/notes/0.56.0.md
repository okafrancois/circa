## New

- Open Skills in the assistant or Command Bar to summarize a tab, compare selected tabs, extract a table as CSV or draft a reply to selected text.
- Create and edit your own Skills with a name, prompt and choice of context. Skills stay separate by profile and sync with iCloud when enabled.
- Choosing a Skill fills the prompt and context for you to review before sending. AI page-access and site restrictions still apply.
