## Smaller

- Circa keeps up to 12 live background tabs by default and puts eligible older tabs to sleep when that budget is exceeded. Visible pages, Split View and protected activity are spared; memory pressure can tighten the budget.
- Choosing Never for Memory Saver disables these automatic tab discards.
