## Fixed

- On streaming sites that open in a WebKit tab, the address field now shows the page's address instead of "Page", follows in-page navigation, and the site controls show the right connection security. Pinned extension buttons work on those tabs again: an extension's popup opens, so a password manager can still search for and copy a password, although extensions cannot fill pages shown by WebKit.
