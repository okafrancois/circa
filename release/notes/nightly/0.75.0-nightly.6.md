## New

- Clicking the address in the sidebar now opens a compact command bar right over it, with the current address selected. Type a search or a new address and press Return to load it in the same tab, or press Tab to search the suggested site.

## Known limits

- Command-L still opens the centered command bar.
- The compact bar appears and disappears without an animation for now.
