## New

- Use Start Errand to describe a browser task. Its pages stay together in an Errand folder, with progress in the assistant and a Stop Errand control.
- Review and approve each proposed page opening, click or text entry before it runs. Stopping the Errand or taking over its page cancels pending actions.
