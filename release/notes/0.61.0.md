Circa now has a public changelog at https://circabrowser.com/changelog.

- Read recent features and fixes on a page that follows the website's light and dark themes.
- Open Release Notes from the update card to read about the version ready to install, before restarting.
- The Release Notes command opens the notes for the version currently installed.
- Future published releases appear on the changelog automatically. Recent notes remain readable if GitHub is unavailable.

Release download statistics are available in GitHub Actions through the Release download statistics workflow. These are file download counts, including repeat downloads and automatic updates, not unique users or installations.
