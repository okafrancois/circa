## New

- Two AI helpers are now available in Settings > AI > Helpers:
- Ask in Find: enter a question ending in `?`, then press Return or Ask. Read a short streamed answer and jump to a validated passage on the page.
- Writing help: select text in a supported editable field to improve it, fix spelling and grammar, shorten it, or translate it. Preview the draft, then choose Replace or Insert Below. Native Undo restores the original text. Ask opens the command bar with the selection ready to edit.
- The existing AI, private-window and page/site access settings apply. Writing help currently supports editable fields in the main page; embedded-frame editors and password fields are excluded.
- This release also bounds cumulative streamed output bytes, including Unicode combining sequences.
