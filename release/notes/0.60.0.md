## New

- Circa now includes a complete French interface, including menus, Settings, browser actions, import messages and AI features. It follows the language selected for the app in macOS and keeps English as the fallback.

- Adjusted French animation labels to fit their existing controls and completed the website-data Settings label.
- Published a complete default keyboard shortcut reference linked from the README.
- Added invented desktop-browser bookmark export compatibility tests; bookmark parsing behavior is unchanged.
- Validation: the full native suite passed (2,990 reported tests), followed by 13 localization/text tests after the final resource corrections. A GitHub-hosted Chromium build and confined French product run passed; the final run completed 36 checks with normal shutdown.
