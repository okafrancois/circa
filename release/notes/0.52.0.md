## New

- Optional **Tidy Today** suggests ways to organize tabs in the current Space. Enable it in Settings → AI → Helpers, choose a ready Quick model, then use **Tidy** beside the Today divider.
- Suggestions never move or archive tabs until you click an action. **Make Folder** groups the selected tabs into a folder in Pinned; **Archive** archives the proposed tabs. Both use native Undo.
- Suggestions use only known tab titles, hosts and identities for up to 40 eligible Today tabs. Page contents are not read for this helper.

## Known limits

- AI remains off by default. Site exclusions, private-window restrictions and the existing privacy and provider settings apply.
