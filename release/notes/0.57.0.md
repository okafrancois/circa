## New

- Choose Generate JavaScript in a Boost's Code editor to draft a site customization with your Chat model. Review or edit the code before enabling it explicitly.

## Fixed

- Rejected or cancelled drafts preserve the previous saved code and its permissions. Changes to the page, Boost or access settings revoke a pending draft.
