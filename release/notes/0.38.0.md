## New

- Use Open File to open local documents and PDFs. The address field displays the selected file's name.
- Back and Forward have navigation history menus, including an option to open a history entry in a background tab.
- Safe Browsing is available as an opt-in setting with your own Google API key, stored on this Mac. Restart after changing it.
- Archive options include Never, separate Little window timing and Clear Archive in the Library. Restored tabs return to their intended location.

## Fixed

- Pinned tabs retain their saved page identity and cached icons. Imported single-color themes display correctly.
- The address field uses the committed page address and its actual connection security. External links reuse Little windows, and expired Little pages are archived.
