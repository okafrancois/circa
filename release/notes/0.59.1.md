## Fixed

- Fixed keyboard focus after adding a split from the Command Bar.
- After choosing Add Right Split, Add Left Split, Add Top Split, Add Bottom Split or Add Split View, you can immediately type the new pane’s address and press Return. Accepting the previous command no longer transfers focus back to the web page.
