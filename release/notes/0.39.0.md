title: Create more kinds of Split View and customize site searches.
---

## New

- Use Option-click and directional split commands to add pages beside or above one another. Split panes support duplication and mute actions.
- Add and edit Site Search shortcuts, and choose Perplexity as a profile's search engine.
- Copy links without trackers and duplicate folders with their contents.
- Command-E cycles pinned extensions, and Little windows use the current extension inventory.

## Fixed

- Duplicating a tab preserves its browsing history. Local file access is remembered when a saved tab is reopened.
