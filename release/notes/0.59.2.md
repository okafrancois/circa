## Fixed

- Fixed the application name shown to macOS launchers. Main and localized display metadata now consistently use Circa, and downloads contain Circa.app. Existing profile, Keychain and updater identifiers are preserved.

## Known limits

- Older in-place updates may retain the previous on-disk application filename. To normalize it, quit the browser and replace the old application with Circa.app from the new disk image, keeping the existing browser data.
