Circa now blocks ads and trackers by itself, with no extension to install. Blocking is on by default for every profile, uses the EasyList and EasyPrivacy filter lists, and leaves Safe Browsing untouched. Turn it off for a whole profile in Settings > General, or allow a single site from the site controls next to the address bar: the page reloads with ads allowed, and the exception covers its subdomains. Private windows do not block yet. Settings gain an Appearance category right after General, gathering Space theme colours, animations, tab hover previews, space around pages, overlay scrollbars, dot Space icons and the app icon; Advanced keeps the technical options. Releases also check passkey support before publishing, ready for system passkeys once Apple grants the browser entitlement; security keys and phone sign-in keep working.
