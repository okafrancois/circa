Rich tab previews, with sharp Retina thumbnails.

- Hover over a sidebar tab to see its cached page preview and title without switching pages.
- Pin or unpin the tab, add it to Favorites, open it in Split View, or open the Assistant with that tab as context. The Assistant action never sends a message automatically.
- Previews appear quickly and switch immediately as you move between tabs. Reduced Motion skips the preview animations.
- Thumbnails use the display's backing resolution for crisp text on Retina screens.
- Hovering does not load sleeping tabs. When no valid cached image is available, the card shows the tab's icon and title.
