## Fixed

- Opening a pinned extension from the floating sidebar now keeps the sidebar visible while its native popup takes keyboard focus. This fixes extension menus disappearing during opening, including Dashlane.
- Preserve the popup anchor through AppKit’s key-window handoff.
- Keep the sidebar open for its focused native child; ordinary hover dismissal resumes when focus returns.
- Continue dismissing on another window or application taking focus. Unrelated visible child windows do not hold the sidebar open.
- Validation: 82 targeted tests and the full native suite (2,992 reported tests) passed. Real Chromium before/after runs reproduced the failure and verified the fix with both an MV3 fixture and the official Dashlane extension in fresh signed, confined test profiles. All four runs quit normally. Dashlane was not signed in; no personal vault was accessed.
