## New

- Clicking the address in the sidebar opens a compact command bar right over it, with the current address selected. Type a search or a new address and press Return to load it in the same tab, or press Tab to search the suggested site.
- When Circa starts and the restored window has no open tab, the New Tab search opens right away, focused and ready to type. Press Escape to keep the empty page.
- **Sync passwords** is a separate switch under Settings › General. It is off on new setups and stays on if you already synced; turning it off stops password sync on this Mac and leaves the copies already in iCloud.
- **Clear Site Data for This Profile…** removes cookies, cache, local storage, IndexedDB and service workers for that profile only; history, passwords and site permissions stay. Clearing one site's data also works when no tab shows that site.
- Private windows are hidden from window captures by other apps.
- Every profile now sends Global Privacy Control, asking sites not to sell or share your data.
- The app icon you choose in Settings › Appearance stays in the Dock when Circa is not running, as long as Circa is kept in the Dock.

## Faster

- Library history search no longer blocks visit recording or sync: searching 200,000 visits for a common word takes 18.5 ms → 1.8 ms, and for a site name 62 ms → 0.8 ms.
- History sync writes only what changed: about 33 KB per sync instead of rewriting about 160 MB for a 200,000-visit history (disk write per cycle 2.7 s → 2 ms).
- Retyping a letter you just deleted shows search suggestions in 275–306 ms → 2–4 ms.
- While the assistant writes, each new word costs 24 ms → 1.0 ms of main-thread time on a 30-message conversation (peaks 52–134 ms → 1.2 ms).
- Opening the assistant panel on a 120 Hz display draws 20 → 47 frames, with no frozen frames.
- Toggling a site permission costs 9.1 ms → 0.007 ms on the main thread.
- Refreshing 100 sidebar rows without a cached icon takes 3 ms → 0.1 ms.
- Session saves during sustained activity: 6.3 → 1.1 per second.

## Fixed

- With nothing typed, the command bar lists your open tabs and favorites first, followed by the keyboard shortcuts help; searching for exactly what you typed comes right after the top suggestion.
- Spaces, tabs, settings and history now sync end-to-end encrypted in iCloud, like passwords already did.
- Deleting a password no longer leaves its secret in the sync record that tells other Macs to delete it.
- Turning iCloud sync off deletes its local caches.
- Deleting history for a time range, a site or a single visit also removes it from the engine's own history.
- Links opened with ⌘-click, ⌥-click into a split, ⇧-click into Peek, or Open Link in New Tab / Split View keep their originating page, so sites no longer receive their strict same-site cookies on cross-site opens.
- Tabs opened in the background with ⌘-click no longer appear blank when you select them.
- Browser-internal debug pages and `javascript:` addresses can no longer be loaded from session restore, AppleScript, link routing or other apps, and AppleScript can no longer run JavaScript in a private window.
- Link routing rules match only a link's site and path; links opened from other apps have embedded user names and passwords removed.
- Link previews refuse local-network and private addresses, including after redirects; update checks no longer send cookies.
- Removing a profile also deletes its web cache and cookie backups, and resumes that cleanup after an interruption. Clearing one site's data also removes its cookies from migration backups.
- Circa no longer writes inside its own app bundle, so its code signature stays valid; macOS no longer keeps its own snapshots of browser windows.
- The Safe Browsing key no longer stays in the environment of processes Circa starts later, and password exports read during an import stay in memory.
- Assistant animations, the Today sidebar accessory and palette transitions follow the display's refresh rate; Space switches no longer write settings during the swipe.

## Smaller

- Refreshed the bundled ad and tracker blocking lists.

## Known limits

- An older Circa cannot read the newly encrypted sync records until it updates; going back manually to 0.74.0 leaves history unavailable (not deleted) until the next update.
- Command-L still opens the centered command bar, and the compact bar over the address appears without an animation.
- Finder keeps showing the default app icon; the Dock may only pick up the chosen icon after the next login.
- The engine deletes a URL's visits for a whole day, so deleting one visit can remove other visits of that URL the same day from the engine's history; history deletions received from another Mac are not yet removed from it.
