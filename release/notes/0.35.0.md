## New

- Settings lets you choose the default download folder or turn on Ask where to save each file.
- The Command Bar offers remote search suggestions and a Delete Suggestion action. Control them with Show search suggestions in Settings.

## Fixed

- Local browser imports remain usable offline and handle newer cookie stores and large sources more reliably.
