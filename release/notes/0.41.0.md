## Fixed

- Text editing, spelling and transformation commands now route to the active editor. Network Inspector, build information copying and revealing browser data also work from their menus.
- Window activation and queued Space changes no longer get stuck in a loop. Closing a window is more reliable, and opening the Library retires a pending floating sidebar reveal.
- Unsupported menu actions are hidden.
