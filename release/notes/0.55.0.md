## New

- Add a GitHub Pull Requests live folder from the Space name’s context menu: **Live Folders → GitHub**. Sign into GitHub in that browser profile first, then retry the command if prompted to sign in.
- Use the folder’s **Pull Requests** submenu to toggle **Created by Me** and **Review Requests**, or refresh immediately. The folder and its configuration survive relaunch.
- Pull requests open in the owning profile. Account bindings remain stable across sign-out; another account cannot silently replace the configured account.

## Fixed

- Support the current GitHub dashboard endpoint, same-document history updates and nested pagination/result schema.
- Keep ordinary imported folders and their separate Space-conversion command distinct from GitHub live folders.

## Known limits

- GitHub.com only, using the owning profile’s normal web session. No personal access token setup is required.
- Both relationship filters are enabled initially; the current default excludes drafts. The folder can be empty when no open pull requests match those filters. Additional assigned/mentioned and repository controls are not exposed in this version.
